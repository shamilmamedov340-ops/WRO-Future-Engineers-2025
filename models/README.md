# 3D models

The chassis and body were 3D-printed from an open design found on YouTube; these are the STL files we printed.

| File | Part |
|------|------|
| `fully_assembled_with_dummy_servo_and_motor.stl` | Whole car assembled, with dummy servo and motor (for reference) |
| `base.stl` | Base plate |
| `tt_frame.stl` | Mount for the TT drive motor |
| `motor_gear.stl` | Gear on the motor shaft |
| `mid_axle.stl`, `mid_axle_gear.stl`, `mid_axle_mount.stl` | Intermediate shaft of the gear train, its gear and mount |
| `drive_axle.stl`, `drive_axle_gear.stl` | Rear drive axle and its gear |
| `bearing_mount.stl` | Bearing mount for the axle |
| `steering_upright_left.stl`, `steering_upright_right.stl` | Front steering uprights (knuckles) |
| `tie_rod.stl` | Tie rod linking both front wheels to the servo |
| `wheel_front.stl`, `wheel_rear.stl` | Wheels |
| `hubcap_front.stl`, `hubcap_rear.stl` | Hubcaps |
| `part2.stl` | Additional part |

> These parts come from a third-party open design, so the MIT license of this repository does not cover them; they belong to the original author.
